# input/ — 参照資料

作業で**参照する**資料（ソースコード、設計書、議事録、受領資料など）を置くフォルダです。

## 置き方

- **自由に置いてかまいません。** 決まったサブフォルダはありません
- **自分で好きなフォルダ構成を作ってもかまいません。** AIはその構成を尊重し、作り直しを勧めません
- 迷ったら、とりあえずこのフォルダの直下に置いてください。散らかってきたら、AIが整理のしかたを提案します（会社の標準フォルダ構成を参考にします）

## ルール

- **ファイルの中身は変更しない**（AIも人間も）
  - 加工したいときは `output/成果物フォルダ/work/data/` にコピーしてから加工する
- **置き場所の整理（移動・フォルダ名の変更）は、利用者の承認があればしてよい**
  - 移動したら、その資料を参照している `output/*/instruction.md` のパスも直す
- **ソースコードは受け取ったフォルダ構成のまま**置く（中を並べ替えない）
- **受け取ったファイルの名前は変えない**（根拠の提示や問い合わせで、相手と同じ名前で話せるように）
- 資料を差し替えたら、影響する成果物の `instruction.md` を見て作業を再実行する
