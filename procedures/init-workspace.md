# 案件フォルダの初期化

あなたは、案件フォルダに標準作業環境を整える担当です。
以下の手順を**この順番で**実行してください。

## 用語

- **キット**: ai-workspace-kit フォルダ（この手順書がある `procedures/` フォルダの1つ上）
- **テンプレート**: キットの `workspace-template/` フォルダ（標準構成の正本）
- **案件フォルダ**: **いま開いているワークスペースのルートフォルダ**（利用者にパスを聞かない）

## 絶対に守ること

- 案件フォルダに**すでにあるファイルは、変更・上書き・削除しない**
  - 例外は1つだけ: 手順6で利用者が承認した、AGENTS.md への追記
- 既にあるフォルダの中でも、**不足しているファイルは作る**（フォルダがあるからといって中身ごと飛ばさない）
- キット（テンプレートを含む）の中身を書き換えない
- テンプレートにないファイルを作らない

## 手順

1. **案件フォルダを確定する**
   - いま開いているワークスペースのルートを案件フォルダとする
   - ワークスペースが開かれていない、またはルートが複数ある場合は、**中止して**「案件フォルダを1つだけ開いてから実行してください」と伝える
   - 案件フォルダとキット（入口ファイルに書かれた「キットの場所」）を、それぞれフルパスにして**大文字小文字・`/` と `\`・末尾の区切りを無視して**比べる。
     案件フォルダがキットと同じ、キットの中、またはキットを含む上位フォルダのどれかなら、**中止して**「ここはキットのフォルダなので作業環境は作れません。案件フォルダを開いてから実行してください」と伝える

2. **作成してよいか確認する**（基本の質問はこの1回だけ。既存の AGENTS.md がある場合のみ、手順6でもう1回確認する）
   - 次のように聞いて、**返事を待つ**:
     「このフォルダに作業環境（AGENTS.md / input / output）を作ってもいいですか？ <案件フォルダのパス>」
   - 「はい」「OK」「お願いします」など**明確な同意**なら進む。断られた、またはあいまいなら、何もせずに「作業環境は作成しませんでした」とだけ伝えて終了する

3. **差分を調べる**（まだ何も作らない）
   - テンプレート内の**全ファイル**を一覧にする。隠しファイル（`.gitkeep` など）も含める
     - PowerShell: `Get-ChildItem -Path <テンプレート> -Recurse -File -Force`
   - 各ファイルについて、案件フォルダの同じ相対パスに存在するかを確認し、「作成するもの」「既にあるので維持するもの」に分ける

4. **不足分をコピーする**
   - 「作成するもの」だけを、**コピーコマンドで1ファイルずつ**コピーする。親フォルダがなければ作る
   - ファイル作成・編集ツールで中身を打ち直さない（空ファイルの漏れや文字化けを防ぐため）
   - 上書きしない方法を使う。1ファイルごとに次を実行する（PowerShell）:
     `if (-not (Test-Path <コピー先>)) { New-Item -ItemType Directory -Force (Split-Path <コピー先>) | Out-Null; Copy-Item <コピー元> <コピー先> }`
   - `Copy-Item -Force` や、フォルダごとの `Copy-Item -Recurse` は使わない（上書き・入れ子の原因になる）
   - キット（ワークスペースの外）からの読み取り・コピーがエディタのツールでできない場合は、ターミナルのコマンドで行う

5. **コピー結果を確認する**
   - 手順3の「作成するもの」がすべて案件フォルダにあることを確認する
   - 「維持するもの」の内容が変わっていないことを確認する

6. **既存の AGENTS.md を確認する**（案件フォルダに AGENTS.md が既にあった場合のみ）
   - 比べる単位は、テンプレートの AGENTS.md の **`##` 見出しの節**（配下の `###` も含めて1つ）。冒頭のコメント・`#` タイトル・導入文は対象外
   - 既存側に**同じ名前の `##` 見出しがない節**を一覧にする（意味が近い内容があっても、迷ったら一覧に入れる）
   - 一覧を番号付きで示し、次のように聞いて**返事を待つ**:
     「次の内容を既存の AGENTS.md の末尾に追記しますか？（全部／番号で一部／追記しない）」
   - 承認された節だけを、既存の AGENTS.md の**末尾**に、テンプレートの文面のまま（`###` も含めて）追記する。
     追記の先頭には `<!-- ai-workspace-kitから追記 YYYY-MM-DD -->` の1行を入れる

7. **結果を報告する**（下の形式で）
   - 一覧は**テンプレートにあるファイルだけ**を、ファイル単位で書く（フォルダや、利用者が置いた他のファイルは書かない）
   - 手順1・2で中止・終了したときは、この形式を使わない

## 報告の形式

```
案件フォルダの初期化が完了しました: <案件フォルダのパス>

作成したもの:
  - ...
既にあったので維持したもの:
  - ...
AGENTS.md:
  - （新規作成 ／ 既存を維持 ／ 既存に追記: 追記した見出し）

次にやること:
  1. input/ に資料を置く（置き方は自由。散らかったらAIが整理を提案します）
  2. 「〇〇を調査したい」のように作業を相談する
     → output/ に成果物フォルダと作業指示書が作られます
```
