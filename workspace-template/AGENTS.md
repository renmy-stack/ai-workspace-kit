# AGENTS.md — この案件の共通ルール

このファイルは、この案件フォルダで作業するAIエージェントと人間の共通ルールです。
作業を始める前に必ず読んでください。

## フォルダの使い方

| フォルダ | 置くもの | ルール |
|---|---|---|
| `input/` | 作業の参照資料（ソースコード・設計書・受領資料など） | 置き方は自由。**中身は変更しない**。詳細は `input/README.md` |
| `output/` | 成果物と、その作り方 | **成果物ごとにフォルダを分ける**。詳細は `output/README.md` |

成果物フォルダの中身:

```
output/NN_成果物名/
├── instruction.md   … 作業指示書（目的・インプット・手順・完了条件）
├── work/
│   ├── scripts/     … 調査・抽出・変換に使ったスクリプト
│   └── data/        … 中間データ・抽出結果
└── （成果物ファイル）
```

## 作業の進め方

### 質問・相談だけのとき
- その場で回答する。フォルダやファイルは作らない。

### 成果物を作るとき
1. 目的・必要なインプット・不足情報を確認する（簡単な作業なら確認は最小限でよい）
2. 作業計画を示し、利用者と合意する
3. `output/_template/` をコピーして `output/NN_成果物名/` を作る（NN は既存の最大番号 + 1、2桁）
4. `instruction.md` を記入してから作業する
5. 作業後、`instruction.md` の「品質確認方法」「完了条件」で成果物を確認し、報告する

### input/ の整理を手伝うとき
- 利用者が自分で作ったフォルダ構成は**そのまま尊重する**。標準構成に合わせるための作り直しは提案しない
- 提案するのは、`input/` の直下にファイルが散らばっているとき、または利用者に頼まれたときだけ（毎回は聞かない）
- 提案は、利用者の既存の構成があればそれに合わせ、なければ `input/README.md` の「整理の参考にするフォルダ構成」に沿う
- 移動・フォルダ名の変更は**利用者の承認を得てから**行う。移動したら、参照している `instruction.md` のパスも直す

## 共通ルール

- インプット（`input/`）のファイルの中身は変更しない（置き場所の整理は承認があればよい）
- 作業指示書・作成過程・成果物をセットで、成果物フォルダの中に置く
- 再実行に必要なスクリプトや中間データは `work/` に残す。不要な一時ファイルは残さない
- 調査・レビュー結果には**根拠と参照元**（ファイル名・行・ページなど）を書く
- **確認できた事実と推測を区別**して書く
- 不明点・未確認事項は、はっきり「未確認」と書く
- 既存ファイルを無断で上書き・削除しない
- 社内の情報セキュリティルールを守る
- 成果物の最終確認は人間が行う
